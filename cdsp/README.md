Source tree for the Central Data Service Playground itself.

- [information-layer](information-layer/README.md): Information Layer Server (Node.js, WebSocket)
- [knowledge-layer](knowledge-layer/README.md): Knowledge Layer (C++), connects the Information Layer to a reasoner
- [reasoner-services](reasoner-services/README.md): Java reasoner services used by the Knowledge Layer (RDF4J)
- [s2dm](s2dm/README.md): S2DM generator for the Information Layer schema and the SHACL shapes
- vissr: VISS data server (git submodule)
